# uni-skills-final

UniSkills - AI-Powered Learning Platform

## Description
UniSkills is an intelligent learning platform that helps students create personalized career paths and track their learning progress with AI-powered insights.

## Features
- Personalized career path generation
- AI-powered learning recommendations
- Progress tracking and assessments
- Interactive learning modules
- Career summary reports

## Tech Stack
- React + Vite
- Appwrite (Backend)
- GROQ API (AI)
- Tailwind CSS
- Framer Motion

## Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. Configure environment variables in `.env`
4. Run development server: `npm run dev`

## Environment Variables
Create a `.env` file with:
- VITE_APPWRITE_ENDPOINT
- VITE_APPWRITE_PROJECT_ID
- VITE_APPWRITE_DATABASE_ID
- VITE_GROQ_API_KEY
- And other required API keys
